# Estudio de Sitio WLAN y Análisis de Cobertura
autores: Abraham Moreno Lopez, Israel Moreno Lopez, Miranda Coronado Juraz Gael, Ruiz Chavez Adalberto, Villa Icedo Jesús Francisco.

Este trabajo es el proyecto final de Comunicación de Datos 2 de la Universidad de Sonora , en el que un equipo de seis estudiantes analizó las redes WLAN de una casa usando el software inSSIDer. Midieron el espectro Wi-Fi en cinco puntos (cuarto, patio trasero, cocina, sala y patio delantero), tanto en la banda de 2.4 GHz como en la de 5 GHz, con el objetivo de identificar redes vecinas, revisar el uso de canales y comparar el comportamiento de ambas bandas.

Los resultados muestran que la banda de 2.4 GHz está muy saturada, con al menos 10 redes chocando entre si, y que la red propia (canal 11) comparte canal con otra red. La banda de 5 GHz está mucho más despejada, aunque la red propia (canal 52) sufre interferencia co-canal con una red vecina que llega con más señal. En cuanto a cobertura, la señal es muy buena cerca del router (-38 dBm en 2.4 GHz) y va bajando hasta -67 dBm en el patio delantero, que es el punto más lejano. Mientras el Link Score de 5 GHz se mantiene estable (82-83), el de 2.4 GHz cae de 97 a 43.
